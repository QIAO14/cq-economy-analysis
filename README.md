# 重庆各区县 2024 年经济数据分析

基于**重庆统计年鉴 2025**官方数据，对重庆 38 个区县的 GDP、产业结构、人均 GDP、人口与城镇化率进行 SQL 分析与可视化。数据真实、可复现。

## 项目背景

重庆是 "大城市 + 大农村" 格局：既有渝中、江北这样的发达中心城区，也有城口、巫溪等欠发达县。通过分析各区县经济数据，回答三个问题：



1. 重庆经济的第一梯队是谁？人均富裕程度和 GDP 总量是否一致？

2. 哪些区县 "人口多但经济弱"（发展滞后）？

3. 三大板块（主城都市区 / 渝东北 / 渝东南）差距有多大？

## 技术栈



* **数据库**：MySQL 9.7（cq\_economy 库，district\_economy 表，38 行 ×8 字段）

* **客户端**：DBeaver（可视化 SQL 开发）

* **可视化**：WPS/Excel（柱状图、散点图）

* **数据来源**：重庆统计年鉴 2025（重庆市统计局官网）

## 分析 SQL 与核心结论

完整脚本见 [sql/analysis.sql](sql/analysis.sql)，共 6 组分析：



| # | 分析               | 关键 SQL 技术                         | 核心结论                                     |
| - | ---------------- | --------------------------------- | ---------------------------------------- |
| 1 | GDP 总量 Top10     | ORDER BY + LIMIT + ROUND          | 渝北区 2769 亿第一，九龙坡、江北、涪陵、渝中为第二梯队           |
| 2 | 人均 GDP Top10     | 排序字段切换                            | 渝中区 29.4 万第一（总量第 5、人均第 1）；长寿区异军突起        |
| 3 | GDP 排名 vs 人均排名差异 | **窗口函数 RANK () + CAST AS SIGNED** | 渝中区排名差 - 4 反差最大（藏富于民）；渝北区总量第 1 人均掉出前 6   |
| 4 | 人口 > 50 万但人均低    | WHERE + 升序 ASC                    | 酉阳县 4.2 万最低；开州区 118 万人口人均仅 6.1 万（典型发展滞后） |
| 5 | 城镇化率 Top10       | 降序排列                              | 渝中区 100% 全境城市化，主城核心区 97%+                |
| 6 | 三大板块差异           | **CASE WHEN 分组 + GROUP BY + AVG** | 主城都市区人均GDP（11.6万）约为渝东北（6.6万）1.8倍，城镇化率差距是主因；对比总量与人均排名，识别出人口规模型（渝北）与产业效率型（渝中、长寿）两类区县发展模式      |

### 技术难点与解决



* **窗口函数 UNSIGNED 溢出**：`RANK()`在 MySQL 返回 BIGINT UNSIGNED（无符号），人均排名 - GDP 排名为负数时直接溢出报错（ERROR 1690）。解决方案：`CAST(RANK() OVER(...) AS SIGNED)` 转成有符号整数再相减。

* **中文路径导入失败**：MySQL `LOAD DATA LOCAL INFILE` 无法读取中文路径文件，需复制到英文路径（如 `E:/ETL/cq_data.csv`）再导入。

* **图表量级问题**：GDP（千亿级）与人均 GDP（十万级）量级差 100 倍，不能放同一张图，需分开做柱状图。

## 可视化图表



1. **GDP Top10 柱状图**：渝北区一枝独秀，前 5 区贡献全市大部分 GDP

2. **人均 GDP Top10 柱状图**：渝中、江北、长寿领跑

3. **人口 vs 人均 GDP 散点图**：38 个点呈 "左上→右下" 分布，直观证明**人口越多、人均 GDP 越低**的区域错配
